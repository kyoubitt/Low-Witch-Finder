# Third-party code and data

The map engine in `engine/tools/lysh/` is **lysh** (MIT, (c) 2026 M33Galaxy, SunnySlopes; its licence is in
`engine/tools/lysh/LICENSE`): exact Minecraft world generation in C. `engine/tools/mineshaft/biome_map.c` is a small
program written for this app that calls it.

The biome trees `engine/tools/lysh/src/biome_trees.h` (one per distinct tree, 1.18 to 26.3) are generated by `tools/accuracy/gen_trees.py`
from the game's own code (dumped locally, never shipped). Earlier versions of this app used the tables from
**cubiomes** (https://github.com/Cubitect/cubiomes), which serialised Mojang's worldgen data; the lysh code still follows its approach. Their licence:
